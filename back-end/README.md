# PRUEBA TECNICA DANY TAX


## Requisitos
+ PYTHON
+ MYSQL

## Levantar ambiente

1. Instalar las librerias que vienen en el archivo requirements.txt
    - Ejecutar el siguiente comando: `pip  install -r requirements.txt`
2. Configurar la conexion a la base de datos en el archivo settings.py
3. Correr el comando para las migraciones: `python manage.py migrate`
